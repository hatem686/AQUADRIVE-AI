# AQUADRIVE-AI Core System

نظام إدارة الاتصال المزدوج والاستجابة السريعة للمركبات المائية الذكية المعزز بنظام ROS 2 و Pixhawk.

## 📌 مكونات النظام الرئيسية
* **`hybrid_comms_node`**: مراقبة التوهين الضوئي عبر الكابل والتحويل التلقائي للقناة اللاسلكية الاحتياطية.
* **`vision_node`**: التعرف على العوائق المائية ومعالجتها على معالج Nvidia Jetson Orin.
* **`pixhawk_bridge`**: الجسر التنفيذي للتواصل مع Pixhawk عبر MAVROS وتفعيل الاستعادة الآلية (Auto-Recovery).
* **`sitl_failover_tester`**: محاكي افتعال الأعطال الميدانية واختبار جاهزية النظام.
