# AQUADRIVE-AI Core System

نظام إدارة الاتصال المزدوج والملاحة الذكية للمركبات المائية المعزز بنظام ROS 2 و Pixhawk.

## 📌 مكونات النظام
* **`hybrid_comms_node`**: إدارة التحويل بين الألياف الضوئية والاتصال اللاسلكي.
* **`vision_node`**: الكشف عن العوائق المائية عبر الذكاء الاصطناعي.
* **`pixhawk_bridge`**: الجسر التنفيذي للتواصل مع Pixhawk والاستعادة الآلية (Auto-Recovery).
* **`geofence_guard`**: السياج الجغرافي وحماية المركبة من الانجراف.
* **`battery_health_monitor`**: مراقبة الطاقة والعودة التلقائية عند انخفاض الشحن.
* **`sitl_failover_tester`**: محاكي الأعطال للاختبار الميداني.
